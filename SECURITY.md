# Security and safety

## Reporting a vulnerability

Please report security issues privately through GitHub's
"Report a vulnerability" button on the Security tab, not in a public issue.
Expect a first answer within a week.

Examples: a way to move a machine through the HTTP API or the agent interface,
or to change the configuration without authorization.

## jogpad is not a safety device

jogpad's STOP key sends the firmware's emergency stop over USB, the host and the
network. It is not an emergency stop in the sense of machine safety standards
and must not replace one. Reports about behaviour that could move a machine
unexpectedly are treated like security issues.
